# Buraco Plus

**Multiplayer card game for mobile · Unity · 2026 · Client project**

Buraco Plus is an online version of Buraco, the popular Brazilian rummy-style card game. Players meet in lobbies, get matched into tables, and play full rounds in real time with Classic and Professional rule sets.

## What I built

- **Complete rules engine** for Classic and Professional Buraco, including melds, canastas, and end-of-round scoring
- **Lobby and matchmaking** over Socket.IO and REST, so players can find and join tables quickly
- **Real-time in-match sync** with Photon Fusion, keeping every player's table state consistent
- **Game server integration** with a NestJS backend that handles players, lobbies, and results

## Tech stack

Unity · C# · Photon Fusion · Socket.IO · REST APIs · NestJS
